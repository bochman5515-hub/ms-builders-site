Команды сервера

Полный список доступных команд MS Builders. Некоторые команды доступны всем игрокам, а некоторые требуют дополнительные права доступа.

Команды для всех игроков

/menu

Открывает меню игрока

/prefix

Открывает меню префиксов

/shop

Открывает магазин

/infoo

Показывает информацию о сервере и игроке

/buypets

Приобрести питомца

/pay <ник> <количество>

Перевести кредиты другому игроку

/pets

Посмотреть своих питомцев

/hdb

Открыть меню кастомных голов

/skin menu

Открывает меню всех скинов

/skin url

Устанавливает скин по ссылке

/skin set

Устанавливает скин по нику игрока

/hub

Вернуться в хаб

/bp

Открыть пропуск

Строительный сервер

/build

Перейти на строительный сервер

/stopbuild

Выйти со строительного сервера

Спонсор

/time

Меняет время суток

/weather

Меняет погоду

/draw

Создание собственных картин

/drawonmap

Создание собственных картин на карте

/tpa

Отправить запрос на телепортацию

/tpahere

Запрос на телепортацию к вам

/mute

Замутить игрока

/unmute

Размутить игрока

/kick

Кикнуть игрока

Будущие команды

В этом разделе будут появляться новые команды после обновлений сервера.
